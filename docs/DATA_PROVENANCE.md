# Data provenance and dependencies

## Data used by active experiments

| Data | Origin | Use |
|---|---|---|
| Maze maps, robots, switches, gate, targets | Generated by `world.py` from integer seeds | Synthetic observations and evaluation |
| Incident service states and faults | Generated by `incident.py` | Synthetic diagnosis/repair sandbox |
| Tool outcomes | Actual local simulator executions | Memory, evidence and independent scores |
| Model responses | Generated for the participant's synthetic experiments via their configured API | Plans, candidate memory, usage records |
| Local learned rules | Derived from stored synthetic sensor observations | Symbolic transfer and optional model context |
| Demo footage | Captured from this local app and FalkorDB Browser | Shows actual runs, recorded playback and evidence |

The application has no importer for private messages, customer records, paywalled documents, login-protected datasets, or personal-data corpora. The research paper is credited by link as inspiration; its contents are not loaded as graph data. Credentials are configuration, never experiment evidence. Source archives exclude `.env`, local metadata, and run-export directories.

This describes application-produced data, not an assertion about arbitrary records someone might manually insert into a database. Use the included Compose setup and a fresh graph for a clean judge environment. The user's existing database is not shipped in the source archive.

## Third-party software

Python, FalkorDB and its Python client, FastAPI/Starlette, Uvicorn, Pydantic, python-dotenv, HTTPX and their dependencies are reused infrastructure. Exact Python dependency versions are in `requirements.lock`. Docker Compose provides local FalkorDB persistence. The frontend uses local HTML/CSS/JavaScript and system fonts; no proprietary design asset pack is included.

Temporary Playwright/Chromium and FFmpeg tooling was used to capture the browser videos; these are not required to run the submitted app. FalkorDB Browser appears as itself in the recording. Codex assistance is disclosed separately in AI_ASSISTANCE.md.

Public source hosting does not establish ownership or override third-party licenses. Participants must confirm their own rights and any team ownership arrangements before submission.

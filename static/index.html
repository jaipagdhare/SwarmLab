MEASURE, THEN CLAIM

Memory is an input.
Success is an observation.

FalkorDB holds the experience, its source, and the path to each consuming agent. The simulator scores the outcome separately. Missing evidence, failed repairs, and provider interruptions stay visible. This prototype does not assume shared memory always wins.
